## 0. 测试方法

- 每用例前 TRUNCATE 7 个业务 schema（ref 字典不清空；md.role 由 session fixture 兜底播种）；
- 管理连接（postgres）+ 应用角色连接（mes_app）双角色；
- 反例断言基于 SAVEPOINT（`conn.transaction()`），不污染 setup 数据；
- 并发用例：ThreadPoolExecutor + 独立 psycopg 连接 + Barrier 同时起跑，SETUP 先行 COMMIT；
- 全部为数据库级验证（SQL 直执行），不经过任何应用层代码。
