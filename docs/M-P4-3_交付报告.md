## 4. 价格版本机制（不可破坏的历史）

- **不可变历史版本**：已生效（effective_from ≤ 今天）的版本**冻结**，改价语义 = 关旧版本 + 开新版本（时间旅行回放用）。
- **单一当前**：`uq_pop_current WHERE is_current` 部分唯一索引保证全局仅一个当前版本；T-17 在 INSERT/UPDATE 当前版本时关闭其它 current。
- **时间旅行**：视图按 `occurred_at::date` 在区间内匹配价格（取 effective_from 最大者），历史报告永不被新价回写。
- **T-17 触发器 `mes_t17_price_version_guard`**（**未引入 btree_gist**）：
  - `pg_advisory_xact_lock(project_operation_id)` 事务级串行化，并发改价不会产生两个当前版本；
  - 已生效历史版本：**禁止 UPDATE / DELETE**；
  - 生效区间**不重叠**（与同 po 其它版本闭开区间相交即拒绝）；
  - 当前开放版本：**仅允许关闭**（改 effective_to / is_current），禁止直接改价/区间；
  - 未来版本（effective_from > 今天）：自由编辑/删除。

## 5. 五种计价口径实现

| 口径 | 度量来源（优先级） | 回退 / 缺失 |
|---|---|---|
| `weight` | `production_measure(weight)` → 回退 `actual_component.actual_weight` | 回退标 `MEASURE_FALLBACK`；两者皆缺 → `MISSING_MEASURE` |
| `piece` | 冻结：1 任务 × 1 正常 attempt = 1 件；**禁止 COUNT(production_report)** | — |
| `length` | `production_measure(cut_length+weld_length+mach_length)` | 0 → `MISSING_MEASURE` |
| `hour` | `SUM(production_report_worker.work_hours)` → 回退 `production_measure(hours)` | 0 → `MISSING_MEASURE` |
| `hole_count` | `production_measure(hole_count)` | 0 → `MISSING_MEASURE` |

> 视图粒度 = **生产任务（attempt）**，跨任务全部报告聚合度量，`occurred_at` 取 `MAX(report.occurred_at)`，`WHERE EXISTS report` —— 满足「禁止按报告重复计数；1 任务×1 正常 attempt=1 件」。

---

## 6. 正常 / 返工 / 报废口径

- **正常成本** `normal_cost`：`attempt = 1`（且 `rework_of_task_id IS NULL`）。
- **返工成本** `rework_cost`：`attempt > 1`（`is_rework = (attempt>1 OR rework_of_task_id NOT NULL)`）。
- **返工绝不覆盖 / 作废 / 删除正常事实**：两行独立存在于 `v_operation_cost_trial`，汇总层 `normal_count/rework_count/normal_cost/rework_cost/total_cost` 分列。
- 报废（`scrap`）：由 `component_scrap_record` 等既有实体承载，本模型不重复定义，成本口径按「未登记完成即不计入已完工会结算」处理（与冻结规则一致）。

## 7. 视图 / 查询入口（API 前置）

- **`eng.v_operation_cost_trial`**：任务级成本试算明细
  - 列：`task_id, component_no, main_project_id, subproject_id, project_operation_id, operation_type_id, custom_name, execute_team_id, occurred_at, attempt, is_rework, price_basis, price, measure_value, amount, anomaly_status`
  - `anomaly_status`：`PRECISE` / `MEASURE_FALLBACK` / `MISSING_MEASURE` / `MISSING_PRICE` / `MISSING_TEAM`
  - **`MISSING_*` 的 `amount` 恒为 NULL，绝不静默计 0**
- **`eng.v_project_production_cost`**：项目→工序→班组→月 汇总（`normal_count/rework_count/normal_cost/rework_cost/total_cost`）
- **`cost_query_service.py`**：`trial_rows(...)` / `project_cost_summary(...)` 参数化只读 SELECT，**不修改任何业务数据**，供 API / 报表复用。
