## 三、新增 DB CHECK（ORANGE-3）

| 约束名 | 表达式 | 与既有约束关系 |
|---|---|---|
| `ck_rework_order_null_chargeable`（**新增，c8**） | `NOT (responsibility_kind IS NULL AND chargeability = 'chargeable')` | 与 `ck_rework_order_pending_chargeable`（`NOT (PENDING AND chargeable)`）一致 |
| `ck_rework_order_pending_chargeable`（既有，c6） | `NOT (responsibility_kind = 'PENDING' AND chargeability = 'chargeable')` | — |

**语义**：`responsibility_kind = NULL ≡ PENDING`；二者在数据库层对 `chargeable` 得到**一致的拒绝**，彻底消除 DB 层不一致。最终计价只认 `effective_chargeability`（视图/服务推导），`stored chargeability` 仅透传展示，杜绝第二计价路径。
