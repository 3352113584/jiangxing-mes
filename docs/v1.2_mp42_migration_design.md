## 2. upgrade 内容

### 2.1 新表 `ship.shipment_pallet`

```sql
CREATE TABLE ship.shipment_pallet (
    id            BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    shipment_id   BIGINT NOT NULL REFERENCES ship.shipment(id)            ON DELETE RESTRICT,
    pallet_id     BIGINT NOT NULL REFERENCES ship.pallet(id)              ON DELETE RESTRICT,
    added_at      TIMESTAMP NOT NULL,
    operator      BIGINT NULL,                          -- 操作人（→ md.user_account，应用层约束，不加 FK 与既有宽表风格一致）
    is_current    BOOLEAN NOT NULL DEFAULT true,
    -- ALifecycleMixin 标准列（与既有 A 类表一致）
    is_active     BOOLEAN NOT NULL DEFAULT true,
    created_at    TIMESTAMP NOT NULL DEFAULT now(),
    updated_at    TIMESTAMP NOT NULL DEFAULT now()
);

-- 约束①（R-SH-2）：一个托盘同一时间只属于一个有效 shipment（草稿或已确认）
CREATE UNIQUE INDEX uq_shipment_pallet_current_pallet
    ON ship.shipment_pallet (pallet_id) WHERE is_current;

-- 约束②（R-SH-2）：同一 shipment 不重复加入同一托盘
CREATE UNIQUE INDEX uq_shipment_pallet_current
    ON ship.shipment_pallet (shipment_id, pallet_id) WHERE is_current;

-- 查询索引：按发运单圈托
CREATE INDEX ix_shipment_pallet_shipment ON ship.shipment_pallet (shipment_id);
```

设计说明：

- **无 stage 列**：行存在即"在单"（draft 加托或已确认），阶段由 `shipment.status` 传导，避免状态双源；
- **is_current=false 的两种含义**：draft 阶段被移出草稿 / 退运释放——均为历史行保留，配合 shipment.status 可区分；
- **NB-1 兼容**：本表对 `mes_app` 授权 SELECT + INSERT + UPDATE（is_current/is_active/updated_at 白名单），DELETE=0（与 NB-1 权限矩阵一致，移出草稿走状态位）；
- **确认后行冻结**由契约 R-SH-2/D-SH-5 承担（service 责任 + 触发器加固待裁决），本迁移不加行级触发器。

### 2.2 `ship.shipment` 加列 `container_id`

```sql
ALTER TABLE ship.shipment
    ADD COLUMN container_id BIGINT NULL
    REFERENCES ship.shipping_container(id) ON DELETE RESTRICT;

CREATE INDEX ix_shipment_container ON ship.shipment (container_id);
```

设计说明：

- **nullable**（Q7）：兼容散运/裸件发运；
- **无唯一约束**（Q7）：一箱可关联多个 shipment（跨主项目混箱 = 一箱多单，各单圈定本主项目托盘）；
- 既有行不受影响（全 NULL 合法）。

- **不加**任何封条字段；
- 不增加任何封条相关发运前置条件。

## 3. downgrade 内容（对称回滚）

```sql
DROP INDEX IF EXISTS ship.ix_shipment_container;
ALTER TABLE ship.shipment DROP COLUMN IF EXISTS container_id;

DROP INDEX IF EXISTS ship.ix_shipment_pallet_shipment;
DROP INDEX IF EXISTS ship.uq_shipment_pallet_current;
DROP INDEX IF EXISTS ship.uq_shipment_pallet_current_pallet;
DROP TABLE IF EXISTS ship.shipment_pallet;
```

> downgrade 前置提示：若表中已有业务数据（发运 Sprint 已上线），downgrade 属破坏性操作，需走数据处置流程，不在本设计范围。

## 4. 执行后验证清单（执行迁移时逐项核对）

1. `\d ship.shipment_pallet`：两条 partial unique 索引存在且 WHERE 条件正确；
2. `ship.shipment.container_id` 存在、nullable、FK 指向 `ship.shipping_container(id)`、无唯一索引；
3. NB-1 权限矩阵补授权：`mes_app` 对 `ship.shipment_pallet` 的 SELECT/INSERT/UPDATE（不授权 DELETE）；
4. alembic `upgrade head` / `downgrade -1` / `upgrade head` 往返通过；
5. 既有 53 用例回归全绿（本迁移不触碰既有表结构，`shipment` 仅加列）。
