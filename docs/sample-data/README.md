# sample-data — 构件清单纯文本审查副本

## 说明

- 两份数据均来自**脱敏后的真实业务 Excel**（客户名、班组人名、编制公司名已脱敏，数据本体未改动）。
- **原 Excel 文件未做任何修改**，本目录文本由只读转换生成。
- 文本文件**仅用于架构审查**（ChatGPT / 人工架构师阅读），替代需要下载 Excel 才能看数据的问题。
- **不得根据当前数据库模型改造数据**：所有行按原始顺序与原始值原样保留，包括空白行、重复行、序号空缺、合计行公式等，一律未整理、未纠正、未重构。
- 每个文件的格式约定：
  - 表格首列 `Excel行` 为审查副本添加的**辅助列**，不属于原数据；
  - 公式单元格呈现为 `公式原文 -> 显示值`（如 `=G2*F2 -> 29.2`），不是只有计算结果；
  - `<br>` 表示单元格内换行；`\|` 为竖线的 Markdown 转义；
  - 合并单元格、空白行、重复行、序号断号、疑似一格多值均在每个 sheet 的「结构与异常注明」小节单独汇总。

- 原始数据实况提示（原样保留，供审查注意）：`构件清单` 表第 1 列序号仅 153 个非空值，其余行为空序号；`2#厂房` 两个 sheet 内容高度相似但结构细节不同（抬头行位置、合并范围、表头行位置、第 11/12 列空列）。
